# Drop art here

Place these PNGs in this folder (Texture Type = **Sprite (2D and UI)**).
Missing files automatically fall back to the procedural placeholder.

## Expected files
- `collectible_bone.png`
- `collectible_scent.png`
- `collectible_photo_piece.png`

**Recommended size:** ~120 x 120 px, centered
**Transparent background:** yes

Pixels Per Unit: 100 (default). See the project README for full art guidelines.
