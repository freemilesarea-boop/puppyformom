# Drop art here

Place these PNGs in this folder (Texture Type = **Sprite (2D and UI)**).
Missing files automatically fall back to the procedural placeholder.

## Expected files
- `bg_sky.png`
- `bg_clouds.png`
- `bg_city.png`
- `bg_trees.png`
- `bg_road.png`

**Recommended size:** sky ~1080x1920 (opaque); clouds/city/trees ~1024x512 wide, horizontally tileable, content bottom-aligned, transparent; road ~512x256 tileable (opaque)
**Transparent background:** yes

Pixels Per Unit: 100 (default). See the project README for full art guidelines.
