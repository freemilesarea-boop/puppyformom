# Drop art here

Place these PNGs in this folder (Texture Type = **Sprite (2D and UI)**).
Missing files automatically fall back to the procedural placeholder.

## Expected files
- `puppy_ver_idle.png`
- `puppy_ver_run_01.png`
- `puppy_ver_run_02.png`
- `puppy_ver_jump.png`
- `puppy_ver_hit.png`
- `puppy_ver_duck.png`  (crouched; drawn low in the canvas)

**Recommended size:** ~400 x 360 px (same canvas for every frame, paws at the very bottom)
**Transparent background:** yes

Pixels Per Unit: 100 (default). See the project README for full art guidelines.
